DeepSeek Harness · 桌面伴侣

多实例并行，
一台桌面。

DSHHelper 在同一台电脑上并行、隔离运行多套 DeepSeek Harness 工作间——内置运行时、四分屏布局，并可用 .dshpack 分发环境。

获取应用 查看仓库

DSHHelper 让 Harness 在桌面上持续运行

模型是 Agent 的灵魂，Harness 让它理解环境并在真实场景中持续工作。DSHHelper 补上桌面这一层——同一窗口内并行多套隔离的 Harness 进程。

桌面 = 多实例 + 运行时

能力

用实例组合你的桌面

多开隔离、缓存式 Node + dsh 运行时，以及可移植制品——本地跑多套 Harness 所需的三块拼图，不必再手撕一堆终端。

多开实例

四分屏布局

多套 dsh 环境并排运行。拖拽标签即可分成 2×2 网格——每个窗格拥有独立进程、端口与数据。

内置运行时

Node + dsh，本地缓存

首次向导把所需运行时下载到数据目录。之后启动跳过等待——环境始终就绪在磁盘上。

可移植制品

导出与导入 .dshpack

把预设、补丁与设置打成单个文件。通过侧栏向导导入，支持机器码或密码等授权方式。

设计思路

默认隔离，
按需分发。

同时看见不止一套 Harness

从侧栏打开实例，再把标签拖到窗口边缘完成分屏。浅色 / 深色外观只影响助手壳界面，不会改写实例内的 Harness 页面主题。

把配好的工作间打成一个文件

.dshpack 打包团队或客户复现环境所需的配置——从实例详情页导出，再通过侧栏向导导入。

制品

导出 → 分享 → 导入

从配好的实例到团队开箱即用的工作间，完整链路一目了然。

开始使用

在你的机器上立刻试用

安装包发布在 GitHub Releases，覆盖 Windows、macOS 与 Linux。

  1. 安装 从 Releases 下载对应平台的安装包。
  2. 向导 选择数据目录、拉取运行时，并创建首个实例。
  3. 四分屏 新建更多实例，拖拽标签排成 2×2 布局。
