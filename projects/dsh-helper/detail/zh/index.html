DSHHelper

多开 Harness，一台桌面。

在同一台电脑上并行、隔离运行多套 DeepSeek Harness 工作间——内置运行时、四分屏布局，可用 .dshpack 分发环境。

查看仓库 获取应用

定位

面向 DeepSeek Harness 的桌面外壳

模型是 Agent 的灵魂，Harness 让它在真实环境中持续工作。DSHHelper 补上桌面这一层：同一窗口内并行多套隔离的 Harness 进程，方便对比、切换，并把配好的工作间交付出去——不必再手撕一堆终端。

桌面 = 多实例 + 运行时

能力

本地跑多套 Harness 所需的一切

多开隔离、缓存式 Node + dsh 运行时，以及可移植制品——按桌面助手该有的方式组合在一起。

多开实例

多套 dsh 环境并排运行。拖拽标签即可分成 2×2 四分屏，每个窗格拥有独立进程与数据。

内置运行时

Node.js 与 DeepSeek Harness 缓存于数据目录。首次向导完成下载，之后启动更快。

.dshpack 制品

导出预设、补丁与设置；导入即可复现工作间，支持机器码或密码等授权方式。

四分屏

同时看见不止一套 Harness

从侧栏打开实例，再把标签拖到窗口边缘完成分屏。浅色 / 深色外观只影响助手壳界面，不会改写实例内的 Harness 页面主题。

制品

把配好的工作间打成一个文件

.dshpack 打包团队或客户复现环境所需的配置，再通过侧栏向导完成导入。

开始使用

在你的机器上立刻试用

安装包发布在 GitHub Releases，覆盖 Windows、macOS 与 Linux。按首次向导完成配置，再用四分屏打开更多实例。

  1. 安装 从 Releases 下载对应平台的安装包。
  2. 向导 选择数据目录、拉取运行时，并创建首个实例。
  3. 四分屏 新建更多实例，拖拽标签排成 2×2 布局。

收尾

为桌面上的 DeepSeek Harness 而做

公开仓库提供文档与安装包。每个标签页内仍是 DeepSeek Harness 本身——DSHHelper 负责让多套实例在同一桌面上一起工作。
