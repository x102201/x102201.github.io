Positioning

A desktop shell for DeepSeek Harness

The model is the soul of an agent. A harness lets that agent work in real environments. DSHHelper adds the desktop layer: several isolated harness processes in one window, so you can compare, switch, and ship configured workspaces without juggling terminals.

Desktop = Instances + Runtime

Capabilities

Everything you need to run harnesses locally

Multi-instance isolation, a cached Node + dsh runtime, and portable packages — composed the way a desktop helper should feel.

Multi-instance

Several dsh environments side by side. Drag tabs to split into a 2×2 quad-pane — each pane keeps its own process and data.

Built-in runtime

Node.js and DeepSeek Harness are cached under your data folder. First-run wizard downloads what you need; later starts stay fast.

.dshpack packages

Export presets, patches, and settings. Import a ready workspace with optional machine-bound or password protection.

Quad-pane

See more than one harness at once

Open instances from the sidebar, then drag tabs to window edges to split. Light and dark shell themes affect the helper UI only — not the pages inside each harness.

Packages

Ship a configured workspace as one file

A .dshpack packages what teammates or clients need to recreate an environment — then import it through the sidebar wizard.

Get started

Try it now on your machine

Installers ship on GitHub Releases for Windows, macOS, and Linux. Follow the first-run wizard, then open more instances in a quad-pane.

  1. Install Download the build for your platform from Releases.
  2. Wizard Pick a data directory, pull the runtime, create the first instance.
  3. Quad-pane Add instances and drag tabs into a 2×2 layout.
