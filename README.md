# 102 vs 201 · 数字对决

`x102201.github.io` 的互动首页：在只有 **0、1、2** 的数字大陆里，加入 102营（蓝）或 201营（橙），
用回合制卡牌把访客变成玩家。

## 玩法

- 费用 = 数字位数；攻击 = 去掉末位；生命 = 末位（0 → 生命 1 + 嘲讽）
- 花 1 水晶给手牌末位追加 0/1/2，把 `10` 养成图腾 **102**、把 `20` 养成 **201**
- 英雄 20 生命；水晶 1→6；随从 4 位；固定 16 张公平牌库
- 102「重组」弃 1 抽 1；201「颠倒」下张费用 -1
- 同数相撞且双方都会阵亡时，由裁判 X 掷硬币裁决唯一存活者

## 留住玩家的设计

- **段位**：青铜 → 白银 → 黄金 → 铂金 → 钻石 → 传奇军师
- **连胜与战报**：连胜加成、最近 8 局
- **12 项成就**：图腾达成、秒杀、无损、满编、绝地翻盘……
- **每日挑战**：迷雾 / 顺风 / 逆风 / 混沌 / 强敌 / 双倍
- **会学习的 X**：记录铺场率与升级率，针对性出牌（不改抽牌随机）
- **本地热座**：同设备 102 vs 201，硬币决定先手，友谊赛不计声望
- **分享战绩**：结算页一键复制 / Web Share

## 技术

纯 HTML / CSS / 原生 JS，零构建、零后端。`localStorage` 键 `tj102201_v2`，Web Audio 合成音效。

**单屏舞台（永不滚动）**：逻辑画布 420×800，按视口等比缩放；五个状态
（主页 / 选阵营 / 换牌 / 对局 / 结算）图层切换。双击 `index.html` 或部署 GitHub Pages 即可运行。
