# 田忌赛马 · 102 vs 201 · 裁判X

`x102201.github.io` 的互动小游戏：选择阵营（102营 / 201营），排兵布阵，
在裁判 X 的裁决下进行田忌赛马式策略对决。

## 玩法

- 双方各拥三匹马：🦄上等马（速3）、🐎中等马（速2）、🐴下等马（速1）
- 秘密布阵到 3 个赛道，三回合两胜制
- 同等级对决由裁判 X 掷硬币裁决
- 对阵经典田忌阵「下上中」可触发隐藏成就

## 留住玩家的设计

- **段位系统**：青铜 → 白银 → 黄金 → 铂金 → 钻石 → 最强军师
- **连胜与战报**：连胜奖励、最近 8 局战报
- **12 项成就**：田忌传人、完胜、大师克星、绝地翻盘……
- **每日挑战**：X 每天设置一条特殊规则（迷雾/顺风/逆风/混沌/强敌/双倍）
- **会学习的 X**：赢得越多，X 越会记住你的阵型并反制——逼你不断变阵
- **忠诚加成**：坚守同一阵营有额外声望
- **本地双人热座**：同一设备 102 营先秘密布阵，交给 201 营再布阵，同时揭晓（不计声望）

## 技术

纯 HTML / CSS / 原生 JS，无构建、无后端。`localStorage` 存档，Web Audio 合成音效。

**单屏舞台（永不滚动）**：逻辑画布固定 420×800，按视口等比缩放居中；五个状态
（主页 / 选阵营 / 布阵 / 对局 / 结算）在同一视口内图层切换，页面不出现滚动条。
直接双击 `index.html` 或部署到 GitHub Pages 即可运行。

## 文件

- `index.html` — 页面骨架（舞台 + 5 个状态层 + 3 个弹窗）
- `style.css` — 暗夜霓虹视觉、画布缩放与层动画
- `game.js` — 全部游戏逻辑（数据 / AI / 动画 / 存档 / 音效 / 热座）
- `PRD.md` — 产品需求与原型
